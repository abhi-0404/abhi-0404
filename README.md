## How I Build

- **Ship the whole system**, not just the model: data, model, API, interface and deployment.
- **Make AI trustworthy**: AI reads and writes, code checks, people decide. Safety-critical numbers never come from a model.
- **Measure it**: tests, evals and validation that mirror the real world, such as golden replays, LLM-judge evals and time-based splits.
